A travel agency website built using HTML, CSS, JavaScript, Node.js, Express.js and MongoDB.
# Troops Travels – Travel Agency Website

## Project Overview
Troops Travels is a travel agency website developed to provide users with a platform to explore travel destinations, browse available packages and manage their travel bookings.

## Features
- Homepage with travel-related information.
- Gallery to explore destinations.
- Travel packages listing.
- User registration and login.
- Booking functionality.
- User and booking data management.

## Technologies Used

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB

## Project Structure

```text
TROOPS TRAVELS/
```

## Database
MongoDB is used to store and manage application data, including user and booking information.

## Project Objective
The project demonstrates the development of a travel agency website by integrating frontend technologies, backend development and database management.
